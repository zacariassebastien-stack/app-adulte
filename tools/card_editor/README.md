# ENCHAIRE Card Editor

Application Flutter Windows autonome qui ouvre directement l’éditeur de cartes
ENCHAIRE et partage son renderer, ses modèles et son catalogue avec
l’application principale.

Les instructions de compilation et de sauvegarde sont dans
`../../docs/card_editor_windows.md`.

La preview peut basculer entre FAIRE, RECEVOIR et MUTUEL. Les deux premières
affichent des PA directionnels opposés; MUTUEL n'affiche qu'une valeur.

Le thème `enchaire_signature_v1` est sélectionné par défaut. Il reprend le fond
anthracite texturé, le double cadre corail, les panneaux sombres et la
hiérarchie serif/sans-serif de la référence visuelle canonique. Tous les
paramètres restent éditables et le thème peut être dupliqué avant déclinaison.
